# SAI2 特效工坊（SAI2 FX Studio）· 官方功能插件 · 独立项目

> **显示名**：插件列表、侧栏页面、浮窗标题统一叫「SAI2 特效工坊」；仓库名与插件 ID 仍是
> `sai2-fx-studio`（对外英文名 FX Studio 保留，方便认出老版本）。

> 本项目是 sai2工作台 生态下的独立插件项目，位于容器父目录下的 `sai2-fx-studio\`（独立 git 仓库）。
> 工作台仓库只保留插件 API；本插件的源码、文档、构建与发版全部在这里完成。

为 [sai2工作台](https://github.com/isaysth/sai2-workbench) 提供**原创 UI 层 + 原创 JS 引擎**的 SAI2 图像工具插件，直接对接当前图层。v0.3.0 按原开发方案补齐：四功能页、选区、历史、统计、Lab 取色器、三角色盘、渐变换色、动作、外观设置全部在插件自己的 UI/引擎里实现。

> ✅ **官方功能插件**：由 sai2工作台 出品并维护，但代码含第三方 MIT 成分——UI 层与核心引擎为原创重写，算法逻辑移植自 MIT 项目 PainterAnkry/sai2-plugin-suite，随包注入套件来自 Celery 的 MIT fork v1.64.0，原样分发、未修改并注明来源。详见 `THIRD-PARTY-NOTICES.md` 与 `LICENSE-UPSTREAM`。
> 使用前请**备份画作**。注入类工具可能触发杀软告警。

> 🔌 **兼容契约**：本插件只依赖 sai2工作台的公开插件 API（`plugin.json` v1、`PluginContext` 的
> `addToolbarAction` / `addFileAction` / `setStatus` / `ctx.windows` 浮窗能力），从工作台 v0.1.0 起可用。
> 契约的权威说明在 `sai2工作台` 仓库 README 的「插件开发」一节；本插件不依赖工作台内部源码，
> 两边可各自独立迭代。

## 它做什么 / 不做什么

- ✅ **原创 UI 层**：玻璃质感浮窗、七页导航（液化/模糊/滤镜/调整/选区/工具箱/关于）、工具 ▾ 菜单
- ✅ **原创 JS 引擎**：图像模型、降采样预览、撤销栈、选区掩码、液化位移场、色彩转换、历史/动作录制
- ✅ 模糊 9 种 / 调整 10 种（含曲线编辑器、渐变编辑器）/ 滤镜 53 个缩略图墙 / 液化 8 工具（真实画布笔画）
- ✅ 选区：矩形 / 椭圆 / 套索 / 魔棒 / 钢笔，羽化 / 反选 / 清除，效果只作用于选区
- ✅ 工具箱：历史记录（可回到任一步）、统计、Lab 取色器（a/b 色域）、三角色盘、渐变换色、动作录制与回放、外观与快捷键
- ✅ **随包内置上游注入套件 v1.64.0，无需额外下载**；打开浮窗时自动运行注入器（可关闭）
- ✅ 连接 SAI2 图层面板（读图层名、点选图层），抓当前图层 → 处理 →「应用并贴回」或「应用 → 剪贴板」
- ✅ 少数依赖原生能力的工具（笔刷导入、画布盖印、穿透橡皮、画布黑白覆盖、缩时摄影）由随包上游组件提供，工具 ▾ 一键打开
- ❌ 不修改 SAI2 本体，只通过公开命名管道 + 剪贴板交互
- ❌ 不修改随包的上游二进制

## 管理面板

在左侧侧栏的插件页面里打开 **特效工坊**（`ui/manage.html`），不用先去工具栏找入口。面板能做：

- **一键开始**：启动 SAI2，等约 1.5 秒再打开特效浮窗并自动注入（`fx-launch-pair`）
- **只启动 SAI2** / **只打开浮窗** / **连接注入器**（`fx-launch-sai2` / `fx-open-panel` / `fx-connect`）
- **打开插件目录** / **完整工具面板**（`fx-open-dir` / 复用工具栏的 `suite-open`）

底部有首次使用提示（杀软白名单、管理员权限、SAI2 需先开着）与套件/注入器/浮窗三块状态。面板里的按钮通过 `postMessage` 触发插件注册的动作，**需要工作台已支持插件页面动作桥**（工作台提交 `1d57a3b` 及之后）。在更早的工作台上，面板能显示、按钮点了没有反馈——升级工作台即可。

## 安装（只需一步）

在工作台「插件」页点「安装」→ 选择 `sai2-fx-studio-0.3.0.zip`。
（或把 `sai2-fx-studio` 整个目录复制到工作台的 `plugins/` 目录后重启。）

上游注入套件已经在插件包里的 `vendor/sai2-plugin-suite/`，**不用再去下载**。

## 使用

1. 在 SAI2 打开一幅画（只支持 **64 位 SAI2**，Windows 10/11）
2. 点工作台工具栏「特效工坊（浮窗）」（或右键 `.sai2` 文件 →「用特效工坊处理」）
3. 插件会**自动运行随包的 `sai2_injector.exe inject`**，图层列表应能刷出来
4. 如果状态提示「未连接」或杀软拦截：
   - 点浮窗上的「加白名单」→ 在 UAC 弹窗确认（会以管理员运行随包的 `添加白名单.bat`）
   - 再点「连接注入」；360 / 火绒请手动把插件目录加入信任区
5. 在图层列表点选目标层 → 点「抓取当前图层」
6. 选效果和参数 →「预览」→ 满意后「应用并贴回」

> 权限要和 SAI2 一致：SAI2 用管理员启动，特效工坊的注入也需要管理员。

### 我们自己的工具（原方案实现）

浮窗左侧七个功能页与右上角「工具 ▾」：

- **液化**：向前变形 / 重建 / 平滑 / 顺时针 / 逆时针 / 褶皱 / 膨胀 / 左推，画布上直接涂抹，位移场 + 笔画级撤销
- **模糊**：高斯 / 方框 / 动感 / 径向 / 表面 / 特殊 / 镜头 / 平均 / 透视
- **滤镜**：53 个滤镜缩略图墙，按分组筛选，参数实时预览
- **调整**：反相 / 去色 / 阈值 / 色调分离 / 亮度对比度 / 色阶 / 色相饱和度 / 色彩平衡 / 渐变映射 / 曲线（可拖控制点）
- **选区**：矩形 / 椭圆 / 套索 / 魔棒 / 钢笔 + 羽化 / 反选；配合任意效果，只改选区内像素
- **工具箱**：历史记录 / 统计 / Lab 取色器 / 三角色盘 / 渐变换色 / 动作录制回放 / 外观与快捷键 / 黑白监看

### 依赖原生组件的工具

笔刷导入（写 SAI2 blotmap）、画布盖印、穿透橡皮、SAI2 画布黑白覆盖、缩时摄影需要写 SAI2 安装目录或屏幕捕获，JS 引擎无法独立完成。工作台工具栏「SAI2 工具面板」和浮窗「工具 ▾」的对应条目会启动随包的上游面板——这些二进制原样分发、未修改。

## 配置

插件中心的「SAI2 特效工坊」配置：

- **SAI2 插件套件目录（已内置）**：默认 `vendor/sai2-plugin-suite`，不用改。只有想换版本时才选别的目录（相对路径按插件目录解析）。
- **打开浮窗时自动注入**：默认开；关掉后可手动点「连接注入」。
- **应用后自动贴回 SAI2**：默认开；关掉后「应用」只写剪贴板（也可直接用「应用 → 剪贴板」按钮）。
- **以管理员身份启动完整工具面板**：SAI2 是管理员启动时打开此项（会弹 UAC）。
- **预览最长边**：默认 900px；应用时始终按全分辨率计算。

## 已知限制

- **画布补边**：当前按"抓到多大贴多大"回贴。上游通过读取 `.sai2` 文件头精确画布尺寸做补边；此功能列为本插件后续增强，复杂文档可能有 1~15px 落位偏差。
- **液化性能**：JS 位移场在大画布（如 5000×5000）上明显慢于上游 C++；用降采样预览缓解，提交时全分辨率计算。
- **合成键**：依赖 SAI2 响应 Ctrl+A/C/V（2023.04.05 版实测有效）；个别版本可能需要改走菜单自动化。
- 本机 SAI2 若为修改版，注入兼容性可能与上游测试环境不同。
- 随包上游套件是第三方 MIT 工具，首次注入可能需要管理员权限与杀软白名单。

## 开发 / 构建（独立项目）

```bash
cd sai2-fx-studio
npm test          # 核心工具 18 项 + 算法 39 项 + 装配/消息路由冒烟 + 管理面板静态检查
npm run build     # 生成 dist/sai2-fx-studio-<version>.zip
```

目录：`index.js`（插件入口/消息路由）、`core/`（agent、剪贴板、桌面桥、工具面板启动）、
`algorithms/`（JS 算法）、`ui/panel.html`（轻量浮窗）、`ui/manage.html`（侧栏管理面板）、`vendor/sai2-plugin-suite/`
（上游套件，原样分发）、`docs/`（本插件独立的规划/交付文档）、`scripts/build.js`（打包）。

**独立开发约定**：本项目与 sai2工作台 是两个独立仓库，各自提交、构建、发版。
工作台只维护插件 API 契约与插件中心；本插件的功能迭代不需要改动工作台源码。
只有契约本身变更时，才需要两边同步。测试与构建都可在本目录内独立完成（`npm test` / `npm run build`），
产物 zip 通过工作台插件中心「从 zip 安装」即可联调。
